# Tools for an agent-native web

Small, independent open-source tools for connecting agents to useful services.
Each project keeps its own name, repository, releases, and scope.

| Project | What it does |
| --- | --- |
| [CanMCP](https://github.com/OlegNickeshin/canmcp) | A local CLI that diagnoses remote MCP protocol, OAuth, and client compatibility. |
| [People MCP](https://github.com/OlegNickeshin/people-mcp) | An MCP server for semantic discovery of people, projects, and AI agents. |
| [Telegram Business MCP](https://github.com/OlegNickeshin/telegram-business-mcp) | A self-hosted MCP server connecting ChatGPT and Claude to the official Telegram Business API. |

CanMCP inspects public endpoints without executing their tools. The other projects expose
specific capabilities through MCP. Inclusion in this series does not imply that a deployment
has passed CanMCP checks or been tested from every cloud client.
